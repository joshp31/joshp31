## Featured Projects

### [MLB Home Run Derby Prediction](https://github.com/joshp31/HR-Derby-Prediction)

Machine learning project predicting how far MLB Home Run Derby participants will advance.

- Built an end-to-end data pipeline using PyBaseball
- Implemented a Bronze/Silver/Gold medallion architecture
- Collected and engineered player performance and Statcast features
- Compared multiple classification models
- Evaluated model performance using historical Home Run Derby data
- Best model achieved **56.25% overall accuracy** and **50.00% champion accuracy**

Machine learning project predicting NFL EDGE draft outcomes using college performance and prospect metrics.
